# Minecraft Mods — учебное веб-приложение

Стек:
- Python 3 + Flask
- PostgreSQL
- pgAdmin 4
- HTML5 + CSS3
- psycopg2
- Jinja2

## 1. Создание БД в pgAdmin 4

1. Откройте pgAdmin 4.
2. Servers → PostgreSQL → Databases → Create → Database.
3. Название: `minecraft_mods`.
4. Откройте Query Tool для `minecraft_mods`.
5. Выполните `schema.sql`.

Если PostgreSQL работает с другим логином/паролем, измените `DATABASE_URL`.

## 2. Запуск

Windows:

```bat
py -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
set DATABASE_URL=postgresql://postgres:ВАШ_ПАРОЛЬ@localhost:5432/minecraft_mods
py app.py
```

После запуска откройте:
`http://127.0.0.1:5000`

## 3. Основные страницы

- `/` — главная
- `/mods` — каталог модов с поиском и фильтрами
- `/mods/<slug>` — страница мода
- `/register` — регистрация
- `/login` — авторизация
- `/add-mod` — добавление мода авторизованным пользователем
- `/forum` — форум
- `/news` — новости

## 4. Минимальные алгоритмы

1. Поиск и фильтрация: SQL-запрос формируется только по выбранным параметрам.
2. Регистрация: пароль преобразуется в хеш через Werkzeug.
3. Авторизация: хеш пароля проверяется без хранения пароля в открытом виде.
4. Скачивание: увеличивается счётчик `downloads`.
5. Добавление мода: запись создаётся в `mods`, а выбранные категории — в `mod_categories`.


## Настройка секретов и запуск после обновления

1. Скопируйте `.env.example` в файл `.env`.
2. В `.env` задайте свой `SECRET_KEY` и `DATABASE_URL`. Не публикуйте `.env`.
3. Установите зависимости: `python -m pip install -r requirements.txt`.
4. Запустите: `python app.py` из папки `minecraft_mods_webapp`.
5. В учебном проекте используется CSRF-защита Flask-WTF, пароль хранится как хеш Werkzeug, а SQL-запросы используют параметры psycopg2.
6. Для реального размещения используйте отдельную роль PostgreSQL с минимальными правами, HTTPS и WSGI-сервер. Не включайте debug.


## Наполнение каталога модами

В `schema.sql` добавлена подборка из 24 дополнительных модов (всего в стартовом каталоге 27 записей). Повторное выполнение файла безопасно для этих записей: дубли по `slug` пропускаются. Если база уже создана, достаточно повторно выполнить обновлённый `schema.sql` в Query Tool базы `minecraft_mods`. Новые записи и связи с категориями будут добавлены, существующие данные не удаляются.
